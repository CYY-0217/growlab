# 任务 2｜探索首页两个视觉预览

> 两个预览为**独立静态 HTML**，不接入正式导航，双击即可在浏览器打开。
> 内容与主要操作结构**完全相同**（标题 / 标本签输入 / 探索按钮 / 方向卡 / 带去练习），仅版式不同，便于公平对比。
> 按钮均标注「预览」，示例方向为占位数据，不伪装功能已实现。

## 打开方式
- 预览 A：`preview-a.html`（标本编辑 + 单色图解）
- 预览 B：`preview-b.html`（标本编辑 + 记忆图谱）
- 共用样式：`preview-shared.css`

## 两方向区别

| | A · 单色图解 | B · 记忆图谱 |
|---|---|---|
| 方向卡排布 | 纵向列表 | 2 列网格 |
| 「建议先试」 | 列表里一张，加 ★ | **越界**跨整行 + 强调描边 + 上浮 |
| 装饰 | 右上角几何轨道 SVG（纯装饰） | 无额外装饰，靠留白 + 越界 |
| 气质 | 更「实验严谨」 | 更「收藏 / 温暖」 |

## 状态覆盖
两个预览都带状态切换按钮：**结果 / 空 / 加载 / 错误**。
窄屏（≤520px）下网格塌成单列。
