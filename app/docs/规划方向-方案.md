## 2. 首轮范围（MVP）
```
文字输入 → 意图解析 → 操作预览 → 确认写入 → 时间冲突检查 → AI 候选调整 → 确认
```
五类意图：**新增 / 修改 / 取消 / 完成回传 / 状态记录**

## 3. 复用 vs 缺口

| 能力 | 现状 | 处理 |
|---|---|---|
| 目标/打卡 | `goals`、`daily_entries`、discipline 接口 | 复用，`goals` 补时间槽 |
| 意图解析 | 无 | 新建（DeepSeek 结构化输出，复用 SYSTEM_COMMON 纪律） |
| 操作预览→确认→可撤销 | `agent_outputs.approved`（雏形） | 新建 `pending_ops` 表 + before_snapshot |
| 时间冲突检查 | 无 | 新建（纯规则引擎，不靠 AI） |
| 候选调整 | `daily_adjustment` 提示词 | 复用改造 |
| 分维度量化 | `checkins`（仅 0~1，计划/实际混淆） | 新建 `metrics` 表 |

## 4. 数据结构（新增 / 扩展）
- **goals 扩展**：`start_time` / `end_time`（HH:MM，可空=不限时段）
- **rest_windows 表**：user 级休息时段（如 23:00–07:00），规则检查用，不自动覆盖
- **pending_ops 表**：`kind / payload / before_snapshot / status(pending|confirmed|cancelled|applied|reverted) / agent_output_id`
- **metrics 表**：`dimension / value / source(self_report|device) / kind(plan|actual)`，**未知=NULL、零=0 分开**，分维度可选，**不做健康总分**

## 5. 交互流程
1. 输入一句话 → 解析出 1..n 个操作（含意图+目标+日期+量）
2. 预览清单：每个操作「做什么 + 影响」，**确认前不写库**
3. 用户逐个确认/取消/纠正 → 写入（带 before_snapshot 可撤销）
4. 写后跑时间冲突规则（重叠/休息时段/容量超限）→ 有冲突给 AI 候选调整
5. 用户确认调整 → 应用

## 6. 技术方案
- **意图解析**：DeepSeek 输出严格 JSON，字段含 `intent / goal_title / goal_id? / date / value / 维度`；解析失败返回原文+询问，不丢输入
- **时间冲突**：纯 Python 规则，确定性、可单测；只产出候选，**绝不自动改任务或休息时段**
- **撤销**：应用时存 before_snapshot，撤销=恢复快照

## 7. 验收用例（重点）
- 否定与纠正：「不是改早上，是改晚上」「算了不改了」
- 相对日期：「明天」「这周五」「下周一」→ 绝对日期
- 同名任务：多个同名目标 → 追问消歧
- 多意图：一句含 2+ 操作 → 列全、逐个确认
- 取消确认、重复提交（幂等）、容量超限（当日总时长超可用时间）
- **确认前不写入** / **失败不丢输入** / **操作可撤销**
- 文字解析测试与（未来）语音测试**分开报告**，不虚构录音结果
