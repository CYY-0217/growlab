# 设计系统 · Art Nouveau（新艺术运动 / 穆夏）方向

> 来源：`~/Downloads/UI设计师Agent技能设定包.md` 第十部分「用户风格偏好模块」，
> 用户明确偏好新艺术运动方向。本文件是前端实现的**唯一设计事实源**，
> 所有视觉决策须回溯到这里的 token 与规则。
> 上游方法：组件库先于页面、无障碍是基因、8px 间距、60-30-10 色彩、状态矩阵完整。

## 0. 风格签名（三个可见决定）

1. **柔化植物性和声**：奶油/羊皮纸底 + 古金 + 橄榄绿，禁止高饱和数字原色。
2. **装饰只住边框与章节过渡**：穆夏式鞭梢曲线/花框只出现在卡片四角、页眉、模块过渡；正文区安静可读。
3. **衬线气质**：正文与标题用宋体/衬线栈，字重 ≤3，留白主动。

## 2. 字体 Token（离线，无外部 CDN）

- **Display（名称 / 短标题）**：衬线装饰感，中文 `"Songti SC","STSong","Noto Serif SC",serif`，西文加 `Georgia, "Times New Roman", serif`；英文短标题可用 italic。
- **正文**：`"Songti SC","STSong","Noto Serif SC",Georgia,serif`，行高 1.6。
- **数据 / 数字**：衬线同源，保持统一（可选 `"Georgia"` 表格数字对齐）。
- 字号阶梯（模块化比例 1.25）：`12 / 14 / 16 / 20 / 25 / 31`（正文 ≥14px）。
- 字重 ≤3：Regular 400 / Medium 500 / Semibold 600。
- **待补充**：若要正宗穆夏体（Poiret One / Elsie / 思源宋体），需本地打包 woff2 文件（离线要求），当前用系统衬线栈兜底。

## 3. 间距 / 圆角 / 阴影

- 间距 8px 阶梯：`4 / 8 / 12 / 16 / 24 / 32 / 48`；组件内边距 < 组件间距 < 区块间距。
- 圆角：`--radius-sm:12px` `--radius-md:16px` `--radius-lg:20px`（0.75~1.25rem，避免机械直边，但交互控件清晰可辨）。
- 阴影：暖色低高程软阴影，如 `0 2px 8px rgba(60,45,20,.08)`。

## 4. 装饰语言（穆夏化纪律）

- 元素：鞭梢曲线、卷须、花瓣、椭圆画框、交织有机边框（SVG 内联，取自 token 色）。
- 位置：**只在**卡片四角、页眉、模块标题分隔、章节过渡；**不进**表单、表格、按钮内部。
- 密度：中等；版面中心保持安静、可读、可行动。
- 动效：藤蔓/花框沿路径生长、柔和淡入，时长 150~500ms，尊重 `prefers-reduced-motion`。

## 5. 组件状态矩阵（每个可交互组件全状态）

`default / hover / active / focus / disabled / error / loading / empty`
- hover：同色相压暗/提亮 4~8%。
- focus：可见焦点环（用 `--gold`，对比度 ≥3:1）。

## 6. 适配说明（本产品是“空间 + 部分仪表盘”）

Art Nouveau 原始规范注明“**慎用于高密度 B 端后台 / 数据仪表盘**”。本产品（个人成长实验室）
含成长地图、实验记录等偏数据页面，因此：

- **框架 / 导航 / 封面 / 章节页**：充分穆夏化（花框、衬线标题、奶油+金）。
- **数据面板 / 表格 / 表单内部**：退到干净可读（羊皮纸面 + 深暖棕字 + 鼠尾草语义色），装饰只留边框。
- 数据可视化（热力图/曲线）：内联 SVG，配色取自 token，不另起色板，不靠颜色单独区分（辅以文字/图案）。
