# 个人成长实验室（GrowLab）
### 不以牺牲身心状态为代价的学习成长 Agent

## 1. 一句话

一个让学生在**安全模拟**里练习、在**真实行动**里验证、逐渐**理解自己**的 AI 成长产品——它不替你决定，而是陪你把“知道”变成“会用”。

## 2. 要解决的问题

大学生常被困在三类冲突里，而普通 AI 助手只会“分开给建议”：

- **学习 vs 健康**：赶作业挤掉吃饭休息，助手一边说“要专注学习”一边说“要规律作息”，却无法在同一天里协调二者。
- **知道 vs 会用**：道理都懂，真遇到“拒绝邀约”“和家人谈压力”“表达分歧”就不会了。
- **启发 vs 行动**：聊完很受启发，现实毫无变化。

## 3. 我们的方案：一条成长闭环

```
探索 → 模拟 → 行动 → 反馈 → 理解自己 → 调整下一次
```

## 4. 一个打动人的例子（演示主线）

> 阿杰深夜邀你打游戏，你想守住 23:30 睡觉，又不想伤感情。

- 第一次你说「改天吧，明天有考试」→ 阿杰理解，关系无损。
- 你**重演**，换成「烦死了别烦我」→ 底线守住了，但阿杰觉得被冷落。
- Agent 对比复盘给出一句关键洞察：**“A 拒绝的是时间，B 拒绝的是人。”**
- 再把这条收获变成现实小实验：下次拒绝时“说感受 + 给替代方案”，回访效果。

这就是产品的价值：**不是告诉你标准答案，而是让你亲身体会不同选择的不同后果。**

## 5. 差异化（候选，需验证，不声称已证明）

1. **反事实重演**：同一选择，换一种说法，比较结果。
2. **从模拟到现实**：模拟不留在聊天里，落成现实小实验并回访。
3. **可编辑记忆**：长期记录有出处，用户可纠正/删除。

## 6. 技术要点

- FastAPI + SQLite + DeepSeek；Agent 每次输入输出落库可追溯。
- “确认前置、可撤销”；“未知不结算”（不伪造数据）。
- 前端为新艺术运动风格，强调“空间感”而非聊天窗口合集。

## 7. 安全与诚实边界

- 不诊断、不治疗、不人格评分、不减肥/训练处方。
- 情境角色反应只是模拟，不代表真人。
- 红旗词自动转介专业支持。
- **短期测试如实标注，未声称改善身心健康。**

## 8. 现状与下一步

- ✅ 已实现：完整闭环可运行（真实模型端到端）。
- ⏳ 待做：更大规模真实试用、竞品对比、长期效果验证。
