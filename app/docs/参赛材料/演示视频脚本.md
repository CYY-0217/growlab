# 演示视频脚本（≤8 分钟）

> 录制方式：录屏 + 旁白（按导师建议，不拍“十分钟菜单巡游”，重点录一条真实闭环 + 一次分支重演）。
> 时长目标 5-8 分钟，控制在 500MB 内。

---

## 分镜

| 段 | 时长 | 内容 | 画面 |
|---|---|---|---|
| 1 开场 | 40s | 一句话痛点：大学生“知道却做不到”“学习与健康冲突”“聊完没行动”。亮出产品名。 | 首页 + 标题 |
| 2 真实困惑 | 30s | 提出真实场景：朋友深夜邀约，想早睡又怕伤感情。 | 探索空间输入一句困惑 |
| 3 进入情境 | 1min | 点「情境剧场」→「拒绝深夜邀约」，展示场景背景、目标、约束。 | 场景卡片 + 开场 |
| 4 第一次回应 | 1min | 温和拒绝 → 阿杰理解 → 三个评估徽章（达成目标✓ 关系友好✓ 真诚表达✓）。 | 对话推进 + 徽章 |
| 5 分支重演 | 1.5min | 点「重演」→ 换冲的话 → 阿杰被冷落 → 对比复盘：“A 拒绝的是时间，B 拒绝的是人”。 | 重演 + 对比复盘（**全片高潮**） |
| 6 落地实验 | 1min | 点「变成现实小实验」→ 个人实验室实验卡 → 回访复盘。 | 实验室 |
| 7 成长记录 | 30s | 成长档案里可编辑/删除的记录。 | 档案 |
| 8 萌宠彩蛋 | 30s | 成长宠物：学习行动给它加经验，喂食/睡觉/玩耍，三围状态。 | 萌宠卡片 |
| 9 收尾 | 40s | 总结：闭环 + 差异化 + 诚实边界（不诊断、模拟非预测、短期测试如实）。 | 回首页 + 结束语 |

**总时长 ≈ 6.5 分钟。**

## 旁白要点（可照读或改写）

1. **开场**：“大学生不缺少知识和建议，缺的是——在真实场景里安全地试错、把启发变成行动。这是我的作品：个人成长实验室。”

2. **痛点**：“比如这个每个人都遇到过的场景——朋友深夜喊你打游戏，你想守住作息，又不想伤感情。普通助手会给你一堆大道理，但它能让你真的练一次吗？”

3. **进入情境**：“点进情境剧场，这里有一个叫阿杰的角色。他不是真人的预言，只是让你安全练习的模拟。”

4. **第一次回应**：“我先温和地拒绝——‘改天吧，明天有考试’。看，阿杰理解了，三个评估显示：达成了目标，关系友好，也真诚表达了。”

5. **分支重演（重点）**：“但我换个说法会怎样？点‘重演’——这次我说‘烦死了别烦我’。底线守住了，可阿杰明显被冷落了。Agent 给出一句洞察：**A 拒绝的是时间，B 拒绝的是人。** 这就是重演的价值：不告诉你标准答案，让你亲身体会不同选择的不同后果。”

6. **落地**：“光有感悟还不够。把这条收获变成一个现实小实验——下次拒绝时‘说感受 + 给替代方案’，两天后回访，看是不是真的更不伤感情。”

7. **萌宠**：“它还会陪你一起长大——你每完成一次练习，就喂它一点经验；你照顾它吃饭睡觉，它陪你一起坚持。”

8. **收尾**：“这就是完整闭环：探索 → 模拟 → 行动 → 反馈 → 理解自己。最后我想诚实说明：角色反应只是模拟，不是对真人的预测；本产品不诊断、不治疗；目前的测试是短期的，我不声称它改善了身心健康——它只是让每一次‘知道’更可能变成‘做到’。”
