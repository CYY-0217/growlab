## 二、一句话定位

一个帮助大学生在**不牺牲身心状态**的前提下完成学习、并在安全模拟与真实行动中**探索想成为怎样的人**的 AI Agent 产品。

## 三、背景与痛点

大学生面临三类真实冲突，普通工具各自为政、无法协调：

1. **赶作业挤掉吃饭休息**——健康约束与学业任务冲突，普通助手分别给“学习建议”和“健康建议”，但无法在同一天里协调二者。
2. **知道道理却用不出来**——面试、表达分歧、拒绝邀约、和家人沟通压力等情境，缺乏安全的练习场。
3. **聊完很有启发、现实毫无变化**——缺少把讨论转化为真实行动、并回看效果的机制。

**区别于普通聊天助手**：本产品不是“你问我答”，而是一个**协调系统**——读约束 → 识别冲突 → 给取舍方案 → 确认 → 更新 → 回访，且允许在关键选择处“反事实重演”。

## 四、产品与功能

产品由五个空间构成（首版已实现、可体验）：

| 空间 | 功能 | 对应闭环环节 |
|---|---|---|
| 探索空间 | 模糊感受 → 可尝试方向（不上来就贴标签） | 探索 |
| 情境剧场 | 关系+健康情境的模拟对话，关键节点可**分支重演** | 模拟 |
| 个人实验室 | 把模拟收获转成现实小实验，回访复盘 | 行动 → 反馈 |
| 成长档案 | 可编辑/删除的成长记忆，有出处 | 理解自己 |
| 成长宠物 | 学习行动喂养它成长，照顾它吃饭/睡觉，全程陪伴 | 陪伴与动机 |

成长宠物（萌宠）把「学习」变成一件有陪伴感的事：完成情境练习、实验复盘等真实行动会给它加经验、让它升级进化；照顾它的吃饭/睡觉/玩耍，也构成一种低摩擦、无惩罚的自我关怀节奏。

**核心创新点（候选，需竞品比较与真实测试验证，不声称已证明有效）**：
1. **反事实重演**——同一关键选择可换一种说法，比较不同结果，理解“为什么”。
2. **从模拟到现实**——模拟结果转化为现实小实验，回来复盘，形成闭环。
3. **可编辑的成长记忆**——长期记录有出处，用户掌握纠正/删除权。

## 五、技术实现

- 后端：Python FastAPI + SQLite（单文件、可携带、可追溯）
- 模型：DeepSeek（OpenAI 兼容接口），情境角色的对话推进、隐藏评估、分支对比、实验计划均由模型驱动
- 前端：单页应用，新艺术运动（Art Nouveau）视觉风格
- 关键设计：**Agent 每次输入/输出全部落库可追溯**；“确认前置”机制（改动前有确认、改动后可撤销）；“未知不结算”（未汇报的数据不伪造）

## 六、健康安全与隐私边界

- 不诊断、不治疗、不做人格评分、不生成减肥/训练处方、不诱导依赖
- 情境角色反应**只是模拟，不代表真人**；多视角共识不当作事实
- 红旗词（自伤/严重身体不适）→ 停止模拟，转介专业/紧急支持
- 敏感自述默认最小化收集、可删除、未经同意不展示

- **未完成 / 待补**：① 更大规模的真实用户试用（当前仅本人 + 少量朋友短期测试）；② 长期效果（未验证，**不声称改善了身心健康**）；③ 竞品对比与差异化验证。

## 八、创新与价值（自评，待验证）

- **对用户**：把“知道”变成“会用”，把“启发”变成“行动”，且不以健康为代价。
- **对赛事主题（OPC）**：单人 + Agent 即可运营，低成本启动、AI 辅助执行、快速迭代验证。
- **诚实边界**：以上为产品假设，非已证明的市场创新或心理学效果。
