# GrowLab · 个人成长实验室

> **不以牺牲身心状态为代价的学习成长 Agent**

一个让大学生在**安全模拟**里练习、在**真实行动**里验证、逐渐**理解自己**的 AI 成长产品——它不替你决定，而是陪你把「知道」变成「会用」。

---

## ✨ 一句话

> 「你刚才那句话，在另一个宇宙里，可能已经绝交了。」

普通 AI 助手只会「分开给建议」：一个说"要专注学习"，一个说"要规律作息"，谁也不会发现它们在打架。GrowLab 把学习与身心放进**同一条闭环**里，让 AI 看见你在拿什么换什么，并陪你把「知道」练成「会用」。

## 🧭 八个空间

| 空间 | 做什么 |
|---|---|
| ⚖️ **规划** | 一句话安排今天——日程与待办一起排，冲突一眼看见，AI 帮你重排到不牺牲自己 |
| 🎭 **情境剧场** | 在关系/健康场景里对话，关键节点可「换种说法」**反事实重演** |
| 📅 **自律** | 今日待办 · 打卡 · 专注计时 · 近 30 天热力图 |
| 🧭 **探索空间** | 把「迷茫」变成几个可试的方向，不上来就贴标签 |
| 🧪 **个人实验室** | 把模拟收获变成现实小实验，回访复盘 |
| 📜 **成长档案** | 可编辑、可删除的成长记忆，每条都有出处 |
| 🐱 **萌宠** | 真实学习行动喂养它成长，照顾它吃饭/睡觉/玩耍 |
| 🃏 **卡牌** | 塔罗式收集，成长落成一张张卡 |

## 🚀 快速开始

```bash
# 1. 安装依赖（Python 3.12）
cd app
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 2. 配置 DeepSeek Key
cp .env.example .env
# 编辑 .env，填入 DEEPSEEK_API_KEY

# 3. 启动
uvicorn main:app --port 8300
# 浏览器打开 http://localhost:8300
```

## 🧱 项目结构

```
growlab/
├── app/                 # GrowLab 主体（FastAPI 单页应用）
│   ├── main.py          # 全部路由
│   ├── database.py      # SQLite 表结构 + CRUD
│   ├── agent_engine.py  # DeepSeek 调用封装
│   ├── planning.py      # 规划闭环：意图解析/时间冲突/操作撤销
│   ├── prompts.py       # 提示词模板
│   └── static/          # 前端（原生 JS，无框架无 CDN）
├── selfagent/           # 提示词宪法（方法论：W-Complete / E-Factor / 未知不结算）
└── 50-day-discipline/   # 原始打卡器（本项目的前身，历史存档）
```

## 🛠 技术栈

- 后端：**Python FastAPI** + **SQLite**（单文件、可携带、可追溯）
- 模型：**DeepSeek**（OpenAI 兼容接口）
- 前端：原生 JS 单页应用，新艺术运动（Art Nouveau）视觉风格，无框架、无 CDN、离线可用

## 🔒 关键设计

- **确认前置、可撤销**：改动前有确认，改动后可撤销
- **未知不结算**：未汇报的数据不伪造，不填 0 冒充"没做"
- **Agent 每次输入/输出全部落库可追溯**
- **量化分维度可选**：区分 计划/实际、自报/设备、未知/零，**不做健康总分**

## ⚠️ 诚实边界

- 不诊断、不治疗、不做人格评分、不生成减肥/训练处方、不诱导依赖
- 情境角色反应**只是模拟，不代表真人**；多视角共识不当作事实
- 红旗词（自伤/严重不适）→ 停止模拟，转介专业支持
- **短期测试如实标注，未声称改善身心健康**
